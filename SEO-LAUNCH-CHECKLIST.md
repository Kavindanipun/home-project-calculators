# BuildEstimate SEO launch checklist

## Before GitHub Pages is indexed
- Run `python configure_site.py https://USERNAME.github.io/home-project-calculators`.
- Confirm no `YOUR-USERNAME` placeholder remains.
- Open every calculator on desktop and mobile.
- Confirm `robots.txt` and `sitemap.xml` load publicly.
- Confirm each page has one H1, a unique title and a unique meta description.

## Google Search Console
1. Add the exact GitHub Pages URL as a URL-prefix property.
2. Verify ownership using one of the methods Search Console offers for that property.
3. Submit `sitemap.xml`.
4. Use URL Inspection for the homepage plus the five calculator URLs and request indexing.
5. Do not repeatedly request indexing every day.

## What to watch for the first 4-8 weeks
- Total impressions trend.
- Queries that get impressions but no clicks.
- Pages ranking roughly positions 8-30: these are the first pages to improve.
- Query wording Google associates with each calculator.
- Mobile usability and unexpected indexing/canonical issues.

## Content improvement rule
Do not publish dozens of thin pages simply to increase page count. Expand only when the next page has a distinct useful calculator, worked example, source or project decision.

## First expansion after data arrives
Prioritize pages based on Search Console impressions. Likely next tool candidates: concrete footing, post-hole concrete, concrete weight, square-footage, mulch, flooring, roof square footage, deck material/cost and stair calculators.

## AdSense
The launch build contains no AdSense code. Wait until the site has useful content, stable navigation and policy pages, then add ads without placing them where they can be confused with calculator buttons or controls. Update the Privacy Policy and consent setup before adding tracking or advertising scripts.
